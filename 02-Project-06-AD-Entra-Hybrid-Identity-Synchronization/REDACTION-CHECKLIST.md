# Project 06 Redaction Checklist

Before publishing, visually confirm the following are not visible:

- Company names
- Domain names
- DNS zone names
- User display names
- Usernames
- Email addresses
- User principal names
- Computer names
- Server names
- IP addresses
- Host records
- Sensitive OU names
- Sensitive group names
- Tenant names
- Microsoft 365 / Entra organization labels
- Dates and timestamps
- AD Connect or sync identifiers
- Infrastructure identifiers

Final review rule: the screenshot should still show the Windows AD, DNS, DHCP, GPO, Entra ID, M365 or Entra Connect task context.
