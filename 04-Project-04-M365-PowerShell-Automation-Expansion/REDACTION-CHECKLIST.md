# Project 04 Redaction Checklist

Before publishing, visually confirm the following are not visible:

- Company names
- User display names
- Usernames
- Email addresses
- Domains
- Tenant names
- Tenant URLs
- SharePoint admin URLs
- SharePoint site URLs
- Microsoft Graph object IDs
- Group IDs
- Directory object IDs
- Mailbox names and SMTP addresses
- CSV file paths if sensitive
- Error request IDs or diagnostic values
- Dates and times
- Tokens or credential-related values

Final review rule: the screenshot should still show the PowerShell command flow and Microsoft 365 automation context.
