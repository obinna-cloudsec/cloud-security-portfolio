# Project 03 Redaction Checklist

Before publishing, visually confirm the following are not visible:

- Company names
- Admin usernames
- Credential or password references
- User display names
- Email addresses
- Domains
- Tenant names
- Tenant URLs
- Sensitive department/team identifiers
- Private channel names if sensitive
- Room names and room mailbox details
- Locations, addresses, and phone numbers
- Policy names if they expose internal identifiers
- Dates and times
- Conferencing details
- Authentication details

Final review rule: the screenshot should still show the Microsoft Teams product area and task context.
