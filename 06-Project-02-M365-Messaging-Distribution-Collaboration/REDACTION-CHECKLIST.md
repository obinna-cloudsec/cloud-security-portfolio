# Project 02 Redaction Checklist

Before publishing, visually confirm the following are not visible:

- Company names
- User display names
- Usernames
- Email addresses
- Domains
- Tenant names
- Tenant URLs
- Outlook calendar dates
- Outlook calendar times
- Meeting titles and invitee details
- Mailbox and recipient details
- Sensitive distribution list details
- Teams membership and team details
- Group mailbox membership details
- Admin identifiers and credential references

Final review rule: the screenshot should still show the Microsoft 365 product area and task context.
